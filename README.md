#Pollo 🐔

Pollo is an advanced Flutter application designed specifically for a veterinary doctor. It provides complete management of the clinic, patients, appointments, and medical records. The project is built following best Flutter practices and SOLID principles, ensuring clean, maintainable, and scalable code.

Features
Manage patient data (animals, medical conditions, notes)
Full appointment scheduling system with reminders
Secure login and data protection
Modern, responsive UI design
Advanced state management (Bloc / Riverpod / GetX)
Professional API handling using Dio
Full separation of layers according to SOLID (Repository, Services, Models, UI)
Technologies Used
Flutter – latest stable version
Dart – programming language
Dio – network and API management
Freezed – immutable data classes and models
GetIt – dependency injection
State Management – Bloc / Riverpod (depending on usage)
SOLID Principles – clean separation of layers and scalable design
JSON Serialization – data handling
